# 还原网页原型全部功能（批次 A：数据与面板层）

盘点结论：三模式/驾驶舱已落地。原型其余功能分两批还原——本轮做**数据与面板层**（网页里主要把玩的部分），编辑器深水区留批次 B。

## 本轮（批次 A）8 项

### 1. mf-vcs worktree 管理 API（~120 行）
git2 0.19 已暴露 worktree API（`Repository::worktree/worktrees/find_worktree`、`Worktree::prune`），纯增量封装到 `git.rs`：
`worktree_list() -> Vec<(name, path)>`、`worktree_create(name, base_branch)`（`.worktrees/<name>` 目录 + 新分支）、`worktree_remove(name)`（prune+删目录）。

### 2. 工作区卡片模型（~80 行）
`.mf-agent/workspaces.json`（serde）：`WorkspaceCard{ id, name, path, branch, status(todo/in-progress/in-review/completed), comment, unread, last_activity }`。主仓一张固定卡 + worktree 卡。读写走 mf-agent 或 mf 内小组件（放 mf/src/board.rs 内部，含 mtime 轮询刷新）。

### 3. 车间卡片墙 `board.rs`（~500 行，新）
左面板第 4 个 tab「车间」（LeftPanel::Board）+ Orca 模式不变：
- **列表视图**：卡片 = 名称/分支/状态徽章/comment/最近活动；徽章点击弹 4 态菜单（gpui `anchored()+deferred()` 自建轻量菜单，gpui 无内置 context menu）
- **泳道视图**：四列 todo/进行中/审阅/完成，卡片 `on_drag<CardId>/on_drop`（gpui 拖拽 API 已确认存在）跨列改状态
- 列表↔泳道头部切换按钮；comment 编辑（复用自绘输入模式）；**＋ 新建工作树**弹窗（名称输入 → git worktree create → 卡片出现）
- 数据变化写回 workspaces.json

### 4. 项目搜索 `search.rs`（~350 行，新）
Ctrl+Shift+F 打开全屏浮层（复用 quick_open 的 overlay 模式）：输入框 + Aa/字/.* 开关 + **按文件分组**的结果（文件头+命中行片段高亮）+ 文件计数。后台线程（`cx.background_executor`）扫描：ignore WalkBuilder 遍历 + 逐文件读取缓存（HashMap<path,(mtime,lines)>），结果流式回填。点击结果 → `open_path` + goto line（`buffer.pos_to_offset(row,0)` + `editor.move_to`，补 editor 公开 goto 方法）。

### 5. 设置两级导航 + Provider 管理（~400 行改动）
settings.rs 改造：左侧两级树（通用[外观/编辑器与终端]、Agent 与模型[Provider 管理/角色绑定]、引擎、版控预留）+ 右侧滚动内容区（嵌套滚动 gpui 已确认支持）。
- **Provider 管理页**：providers 列表（名称/kind 徽章/模型数）+ 行内编辑（kind 切换已有 kind_btn）+ 新建/删除（删除清理 roles 反引用）+ **测试连接**按钮（后台 HTTP GET `{base_url}/models`，结果行内提示）
- 外观页：字号（已有）+ **主题深浅**（见 #6）+ 终端命令（已有）
- 保存仍走 config.toml

### 6. 主题动态化（~150 行 + 全仓替换）
theme.rs 常量改函数：`Theme::X: u32` → `pub fn x() -> u32`，从 `Global`（`App::set_global/observe_global`，zed 同款惯例）读当前 Palette（dark/light 两套色板）。全仓 `rgb(Theme::X)` 机械替换为 `rgb(Theme::x())`（sed 批量）。设置页切换即时生效。

### 7. diff 审阅 hunk 级操作（~200 行）
DiffView 按 `HunkMeta(@@)` 行切分 hunk 组（mf-vcs diff.rs 扁平数组扫描推导，已确认低成本）；每 hunk 头部「保留/拒绝」按钮 + 底部「全部保留/全部拒绝」；**拒绝 = 从原 diff 文本截取该 hunk 段构造 mini-patch → 后台 `git apply -R`（工作区 diff 场景）**；key_context("DiffView") + Alt+Y/Alt+Z（Shift 全部）键位。

### 8. 终端嗅探 + 命令面板键位列（~80 行）
- ConsolePane/驾驶舱缩略格：`tail_lines` 正则匹配 `Ask .* anything`→空闲(绿点)、`Working`→运行(黄点呼吸)、`Worked for`→完成；缩略格状态点升级
- QuickOpen 命令条目 label 追加键位后缀（静态映射表，如 "切换控制台分屏  Ctrl+`"）
