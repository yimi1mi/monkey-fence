# Triage Labels

工程 Skills 使用五个标准 triage 角色。本文件把角色映射到本仓库 GitHub 标签。

| Skill 角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者判断 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整说明，可由 AFK agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或操作 |
| `wontfix` | `wontfix` | 不会处理 |

Skill 提到角色时，使用本表右侧对应的 GitHub 标签。
