# Domain Docs

工程 Skills 探索代码前必须读取与工作范围有关的领域文档。

## 探索前读取

- 根目录 `CONTEXT.md`
- 与当前工作相关的 `docs/adr/`

若文件不存在则静默继续；只有在术语或决策真正收敛时才通过 `/domain-modeling` 创建。

## 结构

本仓库采用单上下文结构：

```text
/
├── CONTEXT.md
└── docs/adr/
```

## 使用统一语言

Issue 标题、计划、规格、测试和代码中的领域概念必须使用 `CONTEXT.md` 定义的术语，不得漂移到其中明确拒绝的同义词。

若需要的概念尚未出现在词汇表中，应先判断它是否是新的真实领域概念；确认后通过 `/domain-modeling` 补充。

## ADR 冲突

若输出与现有 ADR 冲突，必须明确指出冲突并说明为什么值得重新打开决策，不能静默覆盖。
